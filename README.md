## Basic dir

- $HOME/Projects => projects dir
- $HOME/Downloads => default download dir for browser and other apps
- $HOME/Pictures => default images dir
- $HOME/Music => default audio dir
- $HOME/Documents => default doc dir
- $HOME/Videos => default video dir
